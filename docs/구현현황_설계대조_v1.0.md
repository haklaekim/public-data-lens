## 2. 계층별 구현 상세

### 2.1 — 1층: AIRD 정본 파이프라인
- 입력: 목록개방현황 월간 CSV 1개(무손실 보존 `source_json`, SHA-256 앵커)
- 처리: 파싱(cp949/utf-8) → 정규화(매핑표 v1.1, 코드 사전) → 판정(완전성·신선도·지역 — 근거 수준·confidence 동반) → 이슈 관찰(자동 탐지, 전 행 50%+는 카탈로그 수준 축약) → JSON-LD(DCAT·DQV·PROV) → SHACL 검증(표본 500/전수 옵션) → 벌크 정본(ndjson.gz 3종+jsonld) → 수용검사 → 원자적 배포
- AIRD: 표준 MMI 4지표(D5-03·D6-01·D7-01·D7-02, 제2부 v0.87) → 카탈로그 QI_MMI → DM-0(기본 적합성, STRUCT, 참고) — PROV 귀속
- 운영: `scripts/monthly_update.sh` 한 줄(빌드→검사→배포→재기동→로그 정리)
- 현행 데이터: 스냅샷 2026-06 · 96,056건 · 변경 69,676건(2026-02 대비)
