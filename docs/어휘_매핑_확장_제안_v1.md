# 어휘 매핑 확장 제안 v1.1 (초안) — 목록 전 항목의 무손실 의미 표현

- 상태: **승인·적용됨** (2026-07-31) — JSON-LD 확장 구현 완료(보유근거·수집시스템·매체유형·비고·행수·조회/신청수·비용·maintainer·Distribution·DataService·주기 URI·DQV 한계 주석). 보류: D1(전화)·D3(DCMI). D4(어휘 개정 제안)는 후속 환류
- 기반 어휘: [DCAT-AP-KR](https://vocab.datahub.kr/spec/dcat-ap-kr/) — HIKE Lab 발행 공식 명세
  (DCAT-AP 2.1.0 기반, prefix `dcatkr:` = http://vocab.datahub.kr/def/dcat-ap-kr/,
  기관 어휘 `koor:` 동반) — **본 서비스와 동일 주체의 정본 어휘라 채택이 자연스럽다**
- 목표: 목록개방현황의 **모든 항목**이 표준 어휘 또는 명시적 커스텀 어휘(kdp:)로 매핑되어
  JSON-LD에서 의미 손실 없이 표현되게 한다. 현재 미매핑("—") 항목 18종이 대상.

## 0. 원칙

1. **원문 보존 + 병기**: 표준 URI로 "대체"하지 않는다 — 원문 리터럴을 유지하고 표준
   URI를 병기한다(정규화는 참고, 법적 해석 아님).
2. **AIRD는 진단 계층 전용**: AIRD 어휘(aird:)는 적합성·진단(dataType, QI_MMI, DM)을
   표현하는 어휘이지 기술(descriptive) 메타데이터 어휘가 아니다. 목록 항목을 aird:로
   억지 매핑하지 않는다 — 그것이 표준의 취지에 맞다. 기술 계층은 DCAT 계열이 정본.
3. **3계층 어휘 전략**: ①국제 표준(DCAT·DCT·FOAF·vCard·schema.org·DQV) →
   ②**DCAT-AP-KR(dcatkr:)** — 한국 포털 기술 메타데이터 확장(행수·조회수·보유근거·비용 등) →
   ③**kdp:** — 렌즈 고유의 판정·근거·관측 계층 전용(evidenceLevel, completeness,
   sourceSnapshot, 구조 관측). 기술(descriptive) 항목에 kdp를 새로 만들지 않는다.
4. **dcatkr에도 없는 항목은 DCAT-AP-KR 차기 버전 제안 후보로 환류**한다(발행 주체가
   동일 연구실이므로 어휘 개정이 정식 경로다) — 그 전까지만 kdp 임시 표기.

## 2. 기존 매핑의 값 URI 병기 (P1 백로그 통합 — 리터럴 → 표준 URI "병기")

| 필드 | 병기 제안 |
|---|---|
| update_cycle | **EU 발행처 Frequency 권위 테이블 URI**(…/authority/frequency/DAILY 등) — 코드 사전 8종 전부 대응 존재 |
| license_code | KOGL 유형별 **공식 KOGL URI** + CC 계열은 creativecommons.org URI. OTHER/UNSPECIFIED는 원문만 |
| theme_top/sub | 포털 분류체계 SKOS ConceptScheme — **vocab.datahub.kr에 발행**(dcatkr:themeTaxonomy 레인지 그대로) 후 `dcat:theme` URI 병기 |
| regions[] | 이미 ISO 3166-2:KR 코드 — `dct:spatial`에 행정구역 URI(예: KR-11) 병기 |
| org_code | 행정표준코드 기관 URI 체계 확인 후 `dct:publisher`의 @id로 병기(불가 시 kdp URI) |

## 3. 반영 방식 (전부 additive — 재개봉·breaking 없음)

1. JSON-LD Context에 `schema:`·`vcard:`·`dcmitype:` 프리픽스 추가, kdp 신규 용어 매핑
2. `dataset_jsonld()` 확장: Distribution 노드(파일데이터명·포맷), DataService 타입 병기,
   위 표의 속성 추가 — 기존 키 불변, **jsonld 뷰 required 키 불변**(계약 v1.4 minor 불필요
   가능성 높음 — 스키마상 dataset은 open object. 검증 후 판단)
3. **kdp 어휘 문서 발행**: `/projects/datanav/ns/kdp` 정본 URI가 용어 정의(rdfs:label·
   comment·정의 출처)를 반환하게 — "커스텀 어휘의 문서화" 완성
4. SHACL 셰이프 확장 + rdflib 무손실 검증(트리플 수 회귀 테스트)
5. 매핑표 v1.1 갱신("—" 소거) — 모든 항목이 매핑 열을 갖게 됨
