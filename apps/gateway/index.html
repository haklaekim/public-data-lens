공공데이터 렌즈

하고 싶은 일을 말하면 AI Ready 관점으로 정밀하게 투영하는 공공데이터 초점 레이어.

카탈로그 상태 확인 중…

Claude에 연결하기 (커스텀 커넥터)

이 서비스는 화면이 아니라 AI 호스트에 연결하는 MCP 서버로 제공됩니다. 인증 없이 URL 등록만으로 사용할 수 있습니다 (읽기 전용).

…/mcp
  1. Claude 웹/앱 → [설정] → [커넥터] → [커스텀 커넥터 추가]
  2. 위 URL을 입력하고 저장
  3. 대화에서 바로 사용 — 예: “폐교 활용 사업에 참고할 공공데이터 찾아줘”

Claude Code 등 개발 도구는 .mcp.json에 등록합니다:

{
  "mcpServers": {
    "datanav": { "type": "http", "url": "…/mcp" }
  }
}

제공 기능 (Tool 5+1 · Prompt 2 · Resource 5)

search_datasets키워드 + 분류·기관·포맷·주기·라이선스·지역(근거 수준 동반) 필터 검색
get_dataset단건 조회 — card(판단 요약) / normalized / source(원본) / jsonld(정본)
compare_datasets최대 5개 구조화된 사실 비교 (해석 없음)
get_catalog_changes월별 변경 추적 (신규·수정·스냅샷 부재 등 — 부재 ≠ 폐기)
get_catalog_stats주제·기관·포맷·완전성 통계
build_data_plan(Prompt) 목적 한 문장 → 표준 절차의 데이터 활용 계획

모든 판정에는 규칙 버전(rule-id)과 근거가 표기되며, 원문 접근은 공공데이터포털로 연결합니다.

정본 문서 (기계 판독용)

  • Tool JSON Schema 명세 (v1.0.0, 동결)
  • 판정 규칙 레지스트리
  • JSON-LD Context · SHACL 셰이프
  • build_data_plan 공개 문서
  • 서비스 상태(현재 스냅샷·건수)

본 결과는 공공데이터포털 목록 메타데이터 기반이며 실제 데이터의 내용·품질·결합 가능성을 보증하지 않습니다. 공공데이터포털을 대체하지 않으며 모든 원문 접근은 포털로 연결합니다.
